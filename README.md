# Copia — website

Privacy policy and support pages for [Copia](https://github.com/asadbl/copia),
a clipboard manager for macOS.

Published with GitHub Pages from the root of `main`:

- <https://asadbl.github.io/copia-site/>
- <https://asadbl.github.io/copia-site/privacy.html>
- <https://asadbl.github.io/copia-site/support.html>

Both URLs are compiled into the app and submitted to App Store Connect, so they
must stay reachable at these paths.

Plain HTML with inline CSS — no Jekyll, no build step, no dependency on pretty
permalinks.
